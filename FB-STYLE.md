# Facebook text-post style profile (learned from high-performing Japan travel posts)
Method (Ling, 24 Nov; idea from Hao's "Social Post" skill, applied to OTHER pages, not a personal voice):
collect real FB text posts from Japan-travel pages and creators with their reactions / comments / shares, compare each post with that page's usual numbers, and extract what the winners do: first line, length, line breaks, emoji, list vs story, question, link placement, tone. Patterns only; never copy wording.
The Facebook writer (PLAYBOOK 2b) applies this profile to every new FB post. The profile is only "v0 / early" until it rests on ≥ 20 sampled posts from ≥ 5 pages.

## Profile v0 (early, 4 samples)
1. First line = a human, specific hook (humour, news, a season "this week"), never a generic "Planning a trip to Japan?".
2. Sentence 2 gives the practical payoff (when / where / how much), so the post is worth saving or sharing.
3. Short: 2–5 short paragraphs before the link; one idea per post.
4. Practical "this week / this season" lists earn shares; insider alternatives earn comments → end with a question that invites a local tip ("Where would you go instead?").
5. Link posts with only a teaser underperform: the post itself must deliver value, the link is "more detail".
